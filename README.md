# Calculator

A simple calculator built with vanilla HTML, CSS and JavaScript.

## Features

- **Basic operations** — addition, subtraction, multiplication, division
- **Clear button** — AC clears everything, C clears the last entry
- **Decimal support** — work with decimal numbers
- **Divide by zero** — handled gracefully with an error message
- **Keyboard support** — use your keyboard to type numbers and operators

## What I learned

- DOM manipulation with vanilla JavaScript
- Managing state with variables
- Handling user input with event listeners
- Edge cases like dividing by zero

## How to run

1. Clone the repo
```bash
git clone https://github.com/669830/calculator.git
```
2. Open `index.html` in your browser

No installs, no dependencies — just open and use.

## Tech Stack

- HTML
- CSS
- JavaScript (vanilla)
